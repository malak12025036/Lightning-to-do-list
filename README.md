⚡ Lightning McQueen's To-Do List
Project Description
A simple Python CLI app inspired by Cars. It helps Lightning McQueen track his pre-race setup so he can focus on being speed.

When you run the app, an interactive menu lets you add, view, complete, and remove tasks until you're ready to exit.

Features
Add Tasks: Quick-add pre-race prep items to your list.

View Tasks: See everything currently on your agenda.

Mark as Completed: Check off items once they're done.

Delete Tasks: Clear out tasks you no longer need.

Quit: Exit the app whenever you're finished.

(Optional) Persistent Storage: Saves your tasks to a file so they're still there next time you launch the app.

Requirements
Python 3.x

Standard library only (no pip install required).

How to Run
Open your terminal in the project directory.

Run the script:

Bash
python main.py
(Note: Swap main.py for your file name if it's named something else.)

What I Learned & Challenges
Keeping the app active: Building a main menu loop that stays open until the user explicitly chooses to quit took some tweaking.

Input validation: To keep the program from crashing on unexpected inputs, I added checks before running actions to ensure bad inputs are handled gracefully.
